# TomoVis parity fixtures

Inputs, goldens, session files and look-up tables recorded from the original PyQt5 TomoVis.
Everything here except this file and `.gitignore` is generated by
`webui/tools/tomovis_parity/generate.py`; regenerate instead of editing. That folder's
README describes the layout and the keys of every golden file.

`.gitignore` re-includes `*.npy`, which the repository ignores elsewhere.

`qt_image_formats/` comes from `webui/tools/tomovis_parity/qt_image_formats.py` instead: seven
test images (`<case>.png`), the SHA-256 and size of every file Qt 5.15's `QImage.save` wrote for
them in the 16 export formats (`manifest.json`), and the decoded pixels of the smooth-scaled ICO and
of the ICNS files (`decoded.npz`). `tests/webui/test_tomovis_qt_image_writer.py` checks
`webui/tomovis/qt_image_writer.py` against it.
