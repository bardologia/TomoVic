    TomoVis scripts

    The two standalone TomoVis scripts, SlicerMatplotlib.py and VolumeRendering.py, with their hard-coded input path replaced by a file chooser. The slicer steps through the range slices of an hd5 tomogram with the j and k keys; the volume renderer draws the same file as a 3D volume driven by the keys 1, 2, 3, 4, 0, [ and ].
